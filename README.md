# Leonida Atlas

Carte interactive perso pour GTA 6 : véhicules rares, armes uniques, cachettes, cartes Gold, secrets, garages et revendeurs, avec suivi de ses véhicules (garage, ventes, liste de Randy).

- **En ligne :** https://ethrniity.github.io/Leonida-Atlas/
- **Synchronisation :** compte Supabase (projet « Séance musculation », tables `leonida_state` et `leonida_pack`).
- **Nouveautés :** une tâche quotidienne publie les nouvelles trouvailles dans `leonida_pack` ; l'appli les ajoute à l'ouverture.
- **Fond de carte :** chacun importe sa copie du poster officiel (téléchargement gratuit sur le site de GTA 6) via Options → Importer une carte. Elle est gardée dans l'espace privé du compte (bucket Supabase privé `leonida`) et suit sur tous ses appareils. Le poster n'est jamais stocké dans ce dépôt.

Projet de fan, non affilié à Rockstar Games.
